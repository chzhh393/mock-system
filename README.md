# 内外网穿透网关模拟系统

## 项目说明

这是一个模拟内外网穿透网关的系统，用于性能优化验证。

---

## 环境说明

本项目有**两套部署环境**，使用哪套取决于任务文档中的指定：

| 环境 | 外网机器 | 内网机器 | 部署脚本 | 说明 |
|------|----------|----------|----------|------|
| **环境 A/B** | 机器A: 192.168.123.66 | 机器B: 192.168.123.81 | `deploy-registry.sh` | 原始环境 |
| **环境 C/D** | 机器C: 192.168.123.113 | 机器D: 192.168.123.114 | `deploy-cd.sh` | 沙箱环境（无 SSH/Maven） |

**如何选择环境**：
- 查看任务文档（如 `Task-*.md`）中指定的 IP 地址或机器名
- 如果任务提到 **机器A/B** 或 IP **192.168.123.66/81**，使用 `deploy-registry.sh`
- 如果任务提到 **机器C/D** 或 IP **192.168.123.113/114**，使用 `deploy-cd.sh`

## 数据流

```
┌──────────────────────────────────────────────────────────────────────────────────────────┐
│                                      数据流向图                                           │
└──────────────────────────────────────────────────────────────────────────────────────────┘

    ┌────────┐
    │ 客户端 │
    └───┬────┘
        │ ① HTTP 请求
        ▼
┌───────────────────────────────────┐       ┌───────────────────────────────────┐
│        机器 A（外网）              │       │         机器 B（内网）             │
│                                   │       │                                   │
│   ┌─────────┐                     │       │                     ┌───────────┐ │
│   │ scp0005 │ ─────② INSERT──────────────────────────────────▶ │   MySQL   │ │
│   │ (网关)  │                     │       │                     │ (请求表)  │ │
│   └────┬────┘                     │       │                     └─────┬─────┘ │
│        │                          │       │                           │       │
│        │ ⑧ 返回结果               │       │                     ③ Binlog     │
│        │                          │       │                           ▼       │
│   ┌────┴────┐                     │       │                     ┌───────────┐ │
│   │  Redis  │◀────────────────────────────────────────┐        │   Canal   │ │
│   └────▲────┘                     │       │           │        └─────┬─────┘ │
│        │                          │       │           │              │       │
│   ⑦ 写入结果                      │       │           │        ④ 发送消息    │
│        │                          │       │           │              ▼       │
│   ┌────┴────────┐                 │       │           │        ┌───────────┐ │
│   │   outer-    │                 │       │           │        │   Kafka   │ │
│   │  consumer   │                 │       │           │        └─────┬─────┘ │
│   └──────▲──────┘                 │       │           │              │       │
│          │                        │       │           │        ⑤ 消费消息    │
│    ⑥ 消费消息                     │       │           │              ▼       │
│          │                        │       │           │        ┌───────────┐ │
│   ┌──────┴──────┐                 │       │           │        │  scp0006  │ │
│   │    Kafka    │                 │       │           │        │ (穿透服务) │ │
│   └──────▲──────┘                 │       │           │        └─────┬─────┘ │
│          │                        │       │           │              │       │
│    Binlog│                        │       │           │        调用目标服务   │
│          │                        │       │           │              ▼       │
│   ┌──────┴──────┐                 │       │           │        ┌───────────┐ │
│   │    Canal    │                 │       │           │        │  target-  │ │
│   └──────▲──────┘                 │       │           │        │  service  │ │
│          │                        │       │           │        └─────┬─────┘ │
│    Binlog│                        │       │           │              │       │
│          │                        │       │           │         响应结果     │
│   ┌──────┴──────┐                 │       │           │              │       │
│   │    MySQL    │◀────────────────────────────────────┴──────⑤ INSERT ┘       │
│   │  (响应表)   │                 │       │                                   │
│   └─────────────┘                 │       │                                   │
│                                   │       │                                   │
└───────────────────────────────────┘       └───────────────────────────────────┘

流程说明:
① 客户端发起 HTTP 请求到 scp0005
② scp0005 将请求写入机器B的 MySQL 请求表（跨网络 INSERT）
③ 机器B 的 Canal 监听 MySQL Binlog 变更
④ Canal 将变更事件发送到 Kafka (inner_request_binlog)
⑤ scp0006 消费 Kafka 消息，调用 target-service，将响应写入机器A的 MySQL
⑥ 机器A 的 Canal 监听 MySQL Binlog，发送到 Kafka (outer_response_binlog)
⑦ outer-consumer 消费 Kafka 消息，将结果写入 Redis
⑧ scp0005 从 Redis 获取结果，返回给客户端
```

## 快速开始

详细部署步骤请参考 **[DEPLOYMENT.md](./DEPLOYMENT.md)**

### 快速部署命令

**环境 A/B (192.168.123.66 / 192.168.123.81)**：
```bash
# 查看服务状态
./deploy-registry.sh status

# 部署所有服务
./deploy-registry.sh all

# 端到端测试
curl -X POST "http://192.168.123.66:8080/inner/c1/yhzx" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "code=yhzx&paramData={\"test\":\"hello\"}"
```

**环境 C/D (192.168.123.113 / 192.168.123.114)**：
```bash
# 查看服务状态
./deploy-cd.sh status

# 部署所有服务
./deploy-cd.sh all

# 只部署 scp0006（快速迭代）
./deploy-cd.sh scp0006

# 端到端测试
curl -X POST "http://192.168.123.113:8080/inner/c1/yhzx" \
  -H "Content-Type: application/x-www-form-urlencoded" \
```

## 技术栈

- **CDC**: Canal (阿里巴巴开源)
- **消息队列**: Apache Kafka
- **数据库**: MySQL 8.0
- **缓存**: Redis
- **应用**: Spring Boot
- **容器**: Docker
